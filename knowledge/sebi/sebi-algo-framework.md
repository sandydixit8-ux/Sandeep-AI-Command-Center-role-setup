# SEBI Algo Trading Framework — Compliance Summary

Source: SEBI circular SEBI/HO/MIRSD/MIRSD-PoD/P/CIR/2025/0000013 dated 04-Feb-2025
on "Safer participation of retail investors in Algorithmic trading", plus the
Stock Brokers Regulations, 2026 and exchange operational modalities.

## Applicability
The framework is mandatory for all stock brokers since 01-Apr-2026. Retail
investors trading through APIs are covered. Algorithmic orders must operate
within broker-provided, exchange-monitored infrastructure.

## Algo ID tagging
Every algo order must carry a unique algo identifier for audit. From
01-Apr-2026 tagging applies to all algorithmic orders whether generated by
brokers, algo providers, or registered retail traders. The algo ID is the
exchange-registered strategy identifier, distinct from a free-form tag.

## Registration threshold
Retail traders who develop their own algos must register the strategy with the
exchange through their broker only if they exceed the order threshold of
10 orders per second per exchange per client. Below that threshold no individual
strategy registration is required, but all API-based activity is still
categorised as algo orders and subject to broker monitoring and tagging.

## Broker controls
Brokers must enforce: two-factor authentication (2FA) for API access, OAuth
based authentication, IP whitelisting, kill switches, pre-trade risk checks,
and a detailed audit trail of all API orders and trades retained for a minimum
of five years. API sessions must auto-logout before each new trading day.

## Deployment
Algorithms must be hosted on Indian servers. API access operates only through
broker-linked controlled infrastructure. Open, unsecured APIs are not permitted;
access is granted through unique client identification for traceability.

## Black box algos
Providers of black box algorithms (underlying logic not disclosed) must register
as SEBI-registered Research Analysts. Any material change to algorithm logic
requires fresh exchange approval. Transparent, self-developed algos do not need
RA registration.
